AO メインネットが稼働しました。AO の多くの新しいアップデートにより、解説すべきことがたくさんあります。この記事では、新機能の概要を提供し、AO のエコシステム資金調達モデルである Permaweb Index（PI）を紹介します。

## AO とは何か？

[AO](https://ao.arweave.net/#/)は、アクター指向パラダイムからインスパイアされたハイパー並列分散コンピュータです。従来のブロックチェーン計算モデルとは異なり、AO は並列処理により効率的にスケールし、冗長性を削減しながらネットワーク検証可能性を確保し、トラスト要件を最小化します。

2024 年 2 月以来、AO はテストネット上で稼働しており、ユーザーは手数料なしでネットワークと相互作用し、プロトコルをテストして改良できました。現在、AO はメインネット上で稼働しています。

**新機能は？**

1. AO-Core
2. AO Token が転送可能
3. Permaweb Index（PI）

## AO-Core

[AO-Core](https://mirror.xyz/0x1EE4bE8670E8Bd7E9E2E366F530467030BE4C840/ot6Tu0GduY4_kKhoVw9rNPLOPix8DS_Z_3tBPhCK_v0)は、ブロックチェーンスタイルの計算検証をインターネットのインフラ、特に HTTP トランスポートレイヤー内に直接埋め込む強力な新しいプロトコルです。

これは、Web ページの読み込みでも API 相互作用でも、すべての Web リクエストが AO トランザクションとして機能できることを意味します。別々のブロックチェーン統合を必要とする代わりに、AO は既存の Web スタックにシームレスに埋め込まれます。

**なぜこれが重要なのか？**

インターネットには 55 億人のユーザーがいる一方、すべてのブロックチェーン合計で約 3 億人です。既存の Web 標準と統合することで、AO は摩擦なしにこの膨大なユーザーベースを活用できます。

これは昨年正式化された新しいインターネット標準である[HTTP Message Signatures](https://oauth.net/http-signatures/)によって可能になります。これにより、HTTP リクエストのネイティブ署名と検証が可能になり、人々が既に Web を使用する方法を変更することなく、AO トランザクションを検証可能で透明にできます。

さらに、AO はオラクルの必要性を排除します。AO は分散 Web サーバーとして動作するため、AO プロセスとより広いインターネット間のデータ交換は、第三者仲介者に依存することなく、ネイティブに行われます。

**冗長性なしのスケーリング**

Ethereum や Solana などの従来のブロックチェーンネットワークは、複数のノード間で同じプログラムの繰り返し実行に依存しており、これがスケーラビリティを制限します。しかし、AO は新しいハードウェアがネットワークに参加するにつれて全体的な計算能力を増加させます。

**Trusted Execution Environments（TEE）**

[Trusted Execution Environment](https://en.wikipedia.org/wiki/Trusted_execution_environment)（TEE）は、ハードウェアウォレットのセキュリティを持つ CPU のようなものです。これは、ホスティングマシンでさえ処理されているデータを見たり変更したりできない保護された空間で計算が行われることを保証します。

プライバシーを提供するが大幅なパフォーマンストレードオフを伴う[Zero-Knowledge Proofs](https://en.wikipedia.org/wiki/Zero-knowledge_proof)（ZKP）や[Fully Homomorphic Encryption](https://en.wikipedia.org/wiki/Homomorphic_encryption#Fully_homomorphic_encryption)（FHE）と比較して、TEE は最小限の計算オーバーヘッドで高いセキュリティを提供します。

**AO 内での TEE の動作**

1. **正確性の証明** – TEE は計算を効率的に検証でき、信頼性を高めるために複数のハードウェアメーカー間でスタッキングさえできます。
2. **プライベート計算** – ユーザーは基礎データを明かすことなく安全なアプリケーションを実行でき、暗号化トランザクションに似ていますがリアルタイム処理が可能です。

このアプローチは、従来の暗号化手法の膨大な計算コストなしに、AI、金融、その他のデータ機密産業にブロックチェーンレベルの検証可能性をもたらします。

## AO フェアローンチ Token

![Fair launch](/static/images/ao-fair-launch.png)

AO は 100%フェアローンチモデルに従い、プレマイニングトークンなし、インサイダー割り当てなしです。代わりに、AO トークンはネットワーク参加により獲得されます。

AO トークンの 15%がマイニングされた現在、トークンは転送可能になりました。預金者は依然として stETH や DAI などの[アセットをブリッジ](https://ao.arweave.net/#/mint/deposits/)して AO のプレブリッジシステムに参加するか、AR を保有して AO トークンの獲得を続けることができます。

AO のネイティブ収益メカニズムは、エコシステムビルダーとコア開発努力の両方をサポートし、すべての参加者の長期インセンティブを調整します。

## Permaweb Index（PI）

![Permaweb Index](/static/images/pi.png)

Permaweb Index（PI）は Permaweb 上でのデフォルトの交換手段として機能し、アクティブ管理なしにエコシステム全体への幅広いエクスポージャーを提供します。PI は主要な Permaweb アセットの所有権を表すトークンです：

- 1/3 AO
- 1/3 AR
- 1/3 フェアローンチプロジェクト

**PI の動作**

- ステークアセット預金者や Arweave 保有者は、新しいフェアローンチプロジェクトに AO 収益を委託できます。
- 見返りに、それらのプロジェクトのフェアローンチトークンの一部を受け取ります。
- これにより、プロジェクトは 100%のトークンをユーザーに配布しながら、開発資金を確保できます。

[Autonomous Finance](https://www.autonomous.finance/)によって構築されたこの DeFi 技術は、スマートアルゴリズムと自律エージェントの組み合わせを使用して流動性を管理します。

**従来の VC 資金調達とは異なり、このモデルはゼロサム競争を排除し、エコシステム全体での協力的成長を促進します。**

## まとめ

AO メインネットが稼働し、AO-Core、取引可能な AO トークン、Permaweb Index（PI）を含む多くのアップデートが導入されました。AO-Core はブロックチェーンスタイルの検証可能性をインターネットのトランスポートレイヤーに埋め込み、スケーラブルな分散計算を可能にします。フェアローンチ配布により開始された AO トークンは現在取引可能で、エコシステム参加に報酬を与えます。

PI は新しい資金調達モデルを提供し、AR、AO、フェアローンチプロジェクトトークンへのエクスポージャーを提供し、Permaweb 全体での協力を促進します。いくつかのプロジェクトは既に分散マーケットプレイス、AI、永続クラウドインフラのための AO のフェアローンチモデルを活用しています。

AO メインネットは、よりスケーラブルで検証可能で分散化された Web に向けた大きな一歩です。AO 開発の次のステップについてはこの[記事](https://x.com/aoTheComputer/status/1888776191043137748)で詳しく学んでください。**[AO on X](https://x.com/aoTheComputer)**をフォローして最新情報を入手してください。
