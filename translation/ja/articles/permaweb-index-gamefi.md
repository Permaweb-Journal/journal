## I. はじめに

Permaweb Index に2つの新しいプロジェクトが追加されました：StarGrid Battle Tactics の Space Money $SMONEY と ArcAO の $GAME token です。これらのプロジェクトは最先端のゲーミング技術を permaweb にもたらし、AO における GameFi の物語を開拓しています。

現在、コミュニティは Permaweb Index を通じて AO yield を $SMONEY と $GAME に割り当てることで、これらを支援できます。この記事では、両方のプロジェクトと Permaweb Index がどのように機能するかを探求します。

## II. StarGrid Battle Tactics とは何か？

![Stargrid Welcome Screen](https://permaweb-journal.arweave.net/static/images/stargrid.jpeg)

StarGrid Battle Tactics は、AO 上に完全に構築された1対1のターンベースストラテジーゲームです。すべてのインタラクションがトランザクションであり、Arweave に永続的に保存されます。

プレイヤーは1日に4回のランクマッチを受け取ります。$DAI を Staking することで、追加の1日のマッチをアンロックできます。

そしてキャラクターに見覚えがあるでしょう：Vitalik Beauticorn、Space Emperor Tromp、Samurai BZ、Optimos Eloon として プレイしてください。

### $SMONEY 概要

![Stargrid Permaweb Index](https://permaweb-journal.arweave.net/static/images/stargrid-pi.png)

- **ランクマッチで獲得**：ゲームに勝利して $SMONEY を獲得
- **最大供給量**：20,000,000,000
- **配布**：
  - 70%：ランクマッチを通じて獲得
  - 15%：Permaweb Index 経由で mint 可能
  - 7%：エアドロップ
  - 5%：DEX 流動性用に予約
  - 3%：マーケティング、アンバサダー、パートナーに割り当て

StarGrid は、高速ゲームプレイと crypto ネイティブな報酬を組み合わせ、AO と Arweave を使用してすべてのマッチ結果を不変に記録します。

StarGrid を[こちら](https://stargrid.ar.io/)でプレイしてください。

創設者の David と Simone が Arweave Day Berlin で StarGrid を発表した動画を[こちら](https://x.com/StarGridBattle/status/1934008528576094410)で視聴してください。

## III. ArcAO とは何か？

![RuneRealm Welcome Screen](https://permaweb-journal.arweave.net/static/images/runerealm-header.png)

ArcAO は、AO 上で証明可能に公正なゲームとゲーミングインフラストラクチャを構築しています。そのタイトルには [Satoshi's Palace](https://satoshispalace.casino/) と [Rune Realm](https://runerealm-onchain_game.ar.io/) があり、[RandAO](https://www.randao.net/) によって動力を得ています。RandAO は、ゲーム結果の公正性を保証する検証可能な乱数プロトコルです。

### $GAME 概要

![ArcAO Permaweb Index](https://permaweb-journal.arweave.net/static/images/arcao-pi.png)

- **Fair Launch**：10億 token の70%を透明に配布
- **VC 割り当てなし**：プライベート投資家への0%
- **Utility**：GameFi プロジェクトとマーケティングに資金提供

ArcAO は、3つの柱を中心に構造化された GameFi チェーンとして AO をブートストラップすることを目指しています：

1.  **Accelerator Program**：株式とコミュニティサポートと引き換えに初期段階の GameFi プロジェクトに資金提供。
2.  **Ambassador Program**：分散コンテンツチームが permaweb 全体でゲームを宣伝。最後のコホートには500人以上の応募者から80人のクリエーターが含まれました。
3.  **Compounding Investment Pool**：過去の加速化からの利益を将来の GameFi プロジェクトに再投資。

$GAME についての詳細は[こちら](https://docs-arcao_game.openar.dev/docs/investors/overview)をご覧ください。

## IV. Permaweb Index とは何か？

![Permaweb Index Delegate UI](https://permaweb-journal.arweave.net/static/images/delegate-ui.png)

Permaweb Index は、permissionless なエコシステム資金調達メカニズムです。ユーザーがエコシステムプロジェクトを受動的に支援できるようにし、ビルダーに公正で非VCの資金調達オプションを提供します。

**PI token** は、エコシステム全体の多様化された割り当てを表します：

- 33.3% Arweave（$AR）
- 33.3% AO
- 33.3% $SMONEY と $GAME のような Fair Launch プロジェクト

- [Permaweb Index Takeaways](https://permaweb-journal.arweave.net/article/permaweb-index-takeaways.html)

## V. AO yield を Permaweb Index に割り当てる方法

AO yield はカスタマイズ可能です。[Delegate](https://ao.arweave.net/#/delegate/) ページで、ユーザーは獲得した AO を以下に割り当てることができます：

- **PI**：AO、AR、エコシステム token 全体にわたるバランスの取れたインデックス
- **AO**：すべての yield を AO で保持
- **AR**：AO yield を永続的ストレージのための Arweave に変換（まもなく利用可能）

### Fair Launch token への割り当て

![Permaweb Index Delegate UI](https://permaweb-journal.arweave.net/static/images/delegate-ui2.png)

$SMONEY または $GAME を直接サポートするには：

- **Delegate** タブに移動
- 選択したプロジェクトの下の **Details & Add** をクリック
- 割り当てを調整
- **Save Changes** をクリック

これで、プロジェクトの成長を支援しながら、受動的にプロジェクト token を獲得できます。

## VI. まとめ

StarGrid と ArcAO の Permaweb Index への追加は、permaweb コンシューマーアプリケーションの転換を示しています。GameFi は AO で勢いを増しており、これらのプロジェクトは、プロトコルレベルに組み込まれたオープンで透明、検証可能なゲームを提供します。

$SMONEY と $GAME に yield を割り当てることで、ユーザーは token を獲得するだけでなく、次世代の分散化されたゲームとインフラストラクチャに積極的に資金を提供することになります。
