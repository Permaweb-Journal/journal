## はじめに：AR.IOとは何か？

AR.IOは、Arweave ストレージプロトコルと AO compute layer 上に構築された世界初の永続的クラウドネットワークです。分散型で改ざん耐性があり、普遍的にアクセス可能なデータストレージを提供し、データ、アプリケーション、デジタルアイデンティティが永続的で安全、そしてあらゆる場所でアクセス可能であることを保証します。AR.IOは、情報が永遠に存在し、中央集権的な制御から解放されたウェブである permaweb にユーザーを接続します。

AR.IO Network は、オープンで分散的、そして所有者のないネットワークです。このネットワークは AR.IO Gateway と呼ばれる分散化されたノードで実行され、永続的なクラウドサービスプロバイダーとして、permaweb に格納されたデータの読み取り、書き込み、インデックス作成、クエリを実行する能力を持っています。これらの Gateway は、永続的なデータ、ドメインネームサービス（ArNS）、アプリケーションへのアクセスのための一貫性のある信頼できるインターフェイスを、永続的なウェブアドレスを通じて提供します。

ARIO utility token によって動力を得たこのネットワークは、Arweave Name System（ArNS）を通じたドメイン登録を可能にし、Staking をサポートし、Gateway オペレーターに報酬を提供することで、参加への強いインセンティブを作り出します。これらの要素が一体となって、データを保存し、ウェブの可能性を拡張するために構築された永続的なクラウドネットワークのバックボーンを形成しています。

## なぜ従来のウェブサイトが持続しないのか - そして小規模企業にとって不十分な理由

小規模企業は顧客とのつながりにウェブサイトを頼りにしています。しかし、従来のホスティングとドメインは脆弱でリスクが高いのです：

- ドメイン有効期限切れ：ドメインは年単位でリースされます。支払いを忘れると、ウェブサイトアドレスが競合他社やスクワッターに奪われる可能性があります。小規模企業の30%以上が5年以内に意図しないドメインの失効を経験し、トラフィックと信頼を失います。
- 継続的なホスティング費用：月額または年額の費用が積み重なり、予算を圧迫します。ホスティングプロバイダーは、未払い、支払いの問題、または停止により、サイトをシャットダウンまたは削除することがあり、突然のダウンタイムを引き起こします。
- 結果：顧客の信頼失墜、SEOランキングの消失、ブランドアイデンティティの破綻、そして高額な復旧作業。「マリアのベーカリーは、支払い紛争中にホスティングプロバイダーがシャットダウンした際に、ウェブサイトと顧客データを失いました。」これは多くの小規模企業にとって一般的な話でありリスクです。

## AR.IOの問題解決策：永続的で分散化された、手頃な価格のホスティング

AR.IOは Arweave と AO を活用して以下を提供します：

- 一回限りの支払い：一度支払うだけでドメインを登録し、永続的に所有し、ウェブサイトを永続的にホストできます。更新費用や隠れた費用はありません。
- 永続的なドメイン：ArNS では mariasbakery.ar のようなドメインを完全に所有でき、更新なしで有効期限切れのリスクもありません。
- 改ざん耐性のあるストレージ：データは不変で、永続的に保存され、グローバルノード（分散化されたノード）に分散されており、100%のアップタイムと検閲や削除からの保護を保証します。
- 簡単な管理：コーディング不要で、ノーコードビルダーとシンプルなアップロードインターフェイスを提供。この分散化されたアプローチにより、コストを削減し、信頼性を高め、管理を簡素化します。

## このガイドの内容

このガイドでは、AR.IO 上で永続的なウェブサイトを構築し、維持するための4つの簡単な段階を案内します：

1.  ArNS 経由で永続的なドメインを登録
2.  ノーコードツールでウェブサイトを構築
3.  AR.IO の分散化された Gateway にウェブサイトをアップロード
4.  いつでもウェブサイトの内容を更新

![ARIO](https://permaweb-journal.arweave.net/static/images/ario2.png)

**視覚的表現：ワークフロー図** "AR.IO 上で永続的なウェブサイトを作成し、維持するためのステップバイステップのリニアワークフロー。各段階は前段階を基盤として構築され、シームレスな統合を保証します。"

### ステップ1：AR.IO でビジネスドメインを登録

ドメインは permaweb 上でのあなたの永続的なアドレスです。

1.  AR.IO Domain Portal にアクセス。
2.  希望の名前を検索（例：mariasbakery）。
3.  利用可能性と有効性を確認（6-51文字、先頭・末尾にハイフンなし）。
4.  購入またはリース（1-5年）を選択。購入は一回限りの支払いです。
5.  Arweave ウォレット（例：Wander、旧 ArConnect）を接続するか、クレジットカードで支払い。
6.  トランザクションを確認し、ブロックチェーン検証の1-2分を待機。

ヒント：
- ドメインは短く、ブランドに合わせて保持。
- ブランドを保護するため、一般的な誤字も登録。

例：マリアは mariasbakery.ar をクレジットカードで50ドルで購入—更新は不要。

シンプルなツールとウェブサイトビルダーを使用してサイトを作成します。

**Google Sites（無料、マルチページ）**

- HTTrack や SiteSucker などのツールを使用してサイトを静的ファイルとしてエクスポート。

**Carrd.co（手頃な価格、単一ページ）**

- HTML、CSS、JSファイルを含むZIPとしてサイトをエクスポート。

**スターターテンプレート** サイトを素早く開始するためのシンプルなスターターテンプレートを提供しています：[GitHub: AR.IO Small Business Starter Template](https://github.com/IsiomaLight/ar-io-smallbiz-template/) ホームページ、連絡フォーム、画像ギャラリーが含まれ、簡単にカスタマイズできます。

### ステップ3：Permaweb にウェブサイトをアップロードし、マニフェストを作成（マリアのベーカリーを例として）

ウェブサイトを永続的でアクセス可能にします。

- **ウェブサイトファイルを整理**：マリアは、ベーカリーのウェブサイトファイル（index.html（ホームページ）、その他のHTMLページ、CSS、ケーキの画像、JavaScript）をすべて集めて、marias-bakery-site という名前のフォルダーに入れます。
- **[ArDrive Web App](https://ardrive.ar.io/) にアクセス**：マリアはブラウザで ArDrive を開き、Wander（旧 ArConnect）を使用してログインします。
- **パブリックドライブを作成または開く**：彼女は「New」→「New Drive」をクリックし、「Maria's Bakery Website」と名前を付けて、Public に設定します。
- **ウェブサイトフォルダーをアップロード**：パブリックドライブ内で、マリアは「Upload」→「Upload Folder」をクリックし、marias-bakery-site フォルダーを選択し、「Public」がチェックされていることを確認して「Upload」をクリックします。彼女は Wander で AR token の支払いを承認します。
- **マニフェストファイルを作成**：アップロード後、マリアは赤い +New ボタンをクリックし、Advanced → New Manifest を選択します。彼女は index.html ファイルと同じフォルダーを選択し、マニフェストに名前を付け（例：「permasite」、「mariasbakery」）、確認します。彼女は Wander でトランザクションを承認します。マニフェストアイコンは確認中は黄色で表示されます。緑色になったら、彼女の permasite はライブになります！
- **マニフェスト TXID をプレビューしてコピー**：マリアはマニフェストファイルをクリックし、Preview アイコンを使用して新しいタブでサイトを開き、すべてのページとナビゲーションをテストします。その後、マニフェストの Data TX ID をコピーします。これは彼女がドメインに使用する永続的な参照です。

**注意**：マニフェストからプレビューする際、マリアには長いランダムに見えるURLが表示されます。ArNS ドメインをリンクすると、彼女のサイトは選択した人間が読める形式のアドレス（例：mariasbakery.ar.io）で利用可能になります。訪問者は、長い TXID URL ではなく、この分かりやすいドメインのみを使用する必要があります。

### ステップ4：ArNS（.ar ドメイン）でドメインをリンク

永続的なウェブサイトを公式 AR.IO ドメイン（例：mariasbakery.ar）に接続します。

- **ArNS App にアクセス**：Wander（旧 ArConnect）を使用してログインします。
- **.ar ドメインを管理**：「Manage」の下でドメイン（例：mariasbakery.ar）を見つけて「Edit」をクリックします。
- **ドメインのターゲットを更新**：「Target ID」フィールドに、ArDrive からコピーしたマニフェスト TXID を貼り付けます。「Save」をクリックし、トランザクションを承認します（少量の token を使用）。
- **ドメインをテスト**：数分後、ブラウザでウェブサイト（例：[https://mariasbakery.ar](https://mariasbakery.ar/) または [https://mariasbakery.ar.io](https://mariasbakery.ar.io/)）にアクセスします。公式 AR.IO ドメインでウェブサイトがロードされ、ライブサイトを見ることができるはずです！

**注意**：マニフェストからプレビューする際、長いランダムに見えるURLが表示されます。ArNS ドメインをリンクすると、選択した人間が読める形式のアドレス（例：mariasbakery.ar.io）でサイトが利用可能になります。

**ベストプラクティス**：

- すべてのバージョンをバックアップ（例：bakery_v1.zip、bakery_v2.zip）。
- 簡単な参照のためにスプレッドシートでトランザクションIDを追跡。
- アップロード前にローカルでテスト。

「例：マリアは Carrd.co ファイルを編集し、再アップロードし、ドメインのポインターを更新することで、季節のホリデーメニューを追加します。」

## 技術の理解：Arweave、AO、AR.IO

- **Arweave** は blockweave と呼ばれる新しいブロックチェーンライクなプロトコルです。各新しいブロックを以前のランダムなブロックにリンクすることでデータを永続的に保存し、Miners がすべてのデータを安全かつ効率的に保存するインセンティブを提供します。
- **AO（Actor Oriented）** は Arweave 上の分散化されたコンピュート層で、SmartWeave と分散アプリケーションを可能にします。AR.IO は AO 上で動作し、そのコンピュートとストレージ能力を活用します。
- **AR.IO** は Arweave と AO を基盤として構築され、永続的なウェブエコシステムのためのユーザーフレンドリーな Gateway、ドメインサービス（ArNS）、token インセンティブ（ARIO）を提供します。
