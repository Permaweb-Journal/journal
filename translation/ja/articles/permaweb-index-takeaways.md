## I. はじめに

Permaweb Index は Pi Day（3.14）に開始され、ユーザーがプロジェクトトークンと引き換えにエコシステムプロジェクトに AO yield を配分する新しい方法を導入しました。開始からの重要なポイントは以下の通りです。

**まず、Permaweb Index とは何か？**

Permaweb Index は、ユーザーが PI トークンと引き換えに permaweb 上のプロジェクトに AO yield を配分できる分散資金調達メカニズムです。従来の VC 資金調達やトークンプレセールとは異なり、このモデルはプロジェクトがワンタイム投資に依存するのではなく、コミュニティから継続的なサポートを受けることを保証します。

Permaweb Index は、コミュニティがプロジェクトをサポートする公平な機会を提供しながら、ビルダーが開発資金を確保できるようにする新しい資金調達メカニズムです。PI トークンは、アクティブな管理を必要とせずにエコシステム全体への幅広い露出を提供する permaweb 上のデフォルトの交換手段として機能します。PI はコア permaweb アセットの所有権を表します：

- 33.3% $AR
- 33.3% $AO
- 33.3% フェアローンチエコシステムプロジェクト

## II. Permaweb Index プロジェクトを直接サポート

ユーザーは今、PI 自体または信頼する特定のプロジェクトに AO yield を配分することで、Permaweb Index プロジェクトの初期サポーターになることができます。配分された yield はこれらのアプリケーションの開発に資金を提供し、その見返りにユーザーはプロジェクトトークンを受け取ります。

これは公平な資金調達環境を作り出し、コミュニティに日常的に使用するプロジェクトの利害関係を与えます。

## III. 交換手段としての PI

Pi Day X Space で、Sam Williams は、PI が permaweb 上の交換手段に進化するアイデアについて議論しましたが、最終的に市場が決定することを強調しました。PI は 1/3 AR、1/3 AO、1/3 エコシステムフェアローンチプロジェクトで構成されているため、保有者にコアアプリケーションを含む permaweb インフラストラクチャの完全スタックへの露出を与えるため、これは新しいダイナミクスを導入する可能性があります。

PI はまた、S&P 500 が米国経済の状態を反映するのと同様に、エコシステムの健康の指標としても機能する可能性があります。PI は 3 つの相互接続されているが異なる度合いのボラティリティアセットを組み合わせているため、その価値はエコシステムの強さと成長についての洞察を提供するかもしれません。

PI が permaweb 上で広く使用される交換媒体になれば、ほとんどがコアトークンを交換手段として使用する今日のブロックチェーンエコシステムの機能からの変化を表すでしょう。

## IV. 評判システムとしての PI

Permaweb Index は開発者にプロジェクトの資金調達の新しい方法を提供するだけでなく、エコシステム内のプロジェクトのための**評判システム**も導入します。

どのプロジェクトもフェアトークンを開始できますが、ユーザーによって配分される yield の量が**信頼のシグナル**として機能します。高品質のプロジェクトはより多くの yield を引き付け、弱いプロジェクトは牽引力を得るのに苦労するでしょう。

PI はプロジェクト配分に基づいて自動的にリバランスするため、低価値プロジェクトは時間とともに自然にインデックスのより小さなシェアを構成します。このダイナミクスは低品質プロジェクトをフィルタリングし、エコシステムのより正確な表現を作成するのに役立ちます。

とはいえ、**悪意のあるアクターは許可不要システムには常に存在します**。PI はプロジェクトがコミュニティをラグプルすることを困難にしますが、いつものように、どのプロジェクトに投資する前にも自分自身で調査を行ってください。

## V. 結論

Permaweb Index は**プロジェクトの資金調達、評判のシグナル、そして場合によっては交換手段としても機能する**新しい方法を導入します。まだ初期段階ですが、ユーザーが PI とエンゲージする方法がエコシステムでどのように進化するかを形作るでしょう。

Permaweb Index Fair Launch Creator の完全開始についての詳細情報にご期待ください。間もなくすべてのプロジェクトが許可なくプロジェクトを開始できるようになりますが、現在チームは初期リリースのセキュリティと安定性をテストしています。
